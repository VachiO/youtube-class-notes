# POL2102

## กำหนดการและการประเมินผล

- สอบปลายภาคนอกตารางเรียน วันที่ 8 ตุลาคม 2569
- ข้อสอบ 3 ข้อ เลือกทำ 2 ข้อ รวม 80 คะแนน และเปิดหนังสือได้
- Quiz 20 คะแนน ให้นำมาส่งในวันสอบปลายภาค วันที่ 8 ตุลาคม 2569

ข้อมูลกำหนดการข้างต้นตรวจจากหน้าหลักของรายวิชา ภาค 1/2569 เมื่อวันที่ 25 สิงหาคม 2569 ควรตรวจประกาศล่าสุดของโครงการอีกครั้งก่อนวันสอบ

## ความคืบหน้าชั้นเรียน

- คาบ 17 กันยายน 2569 อาจารย์แจ้งว่าจะบรรยายต่อเรื่องเส้นทางที่ประเทศเข้าสู่ระบอบผสมในสัปดาห์ถัดไป ตามตารางปกติคือวันพฤหัสบดีที่ 24 กันยายน 2569
- คาบ 17 กันยายนไม่มีประกาศเปลี่ยนวันสอบ คะแนน Quiz หรือกำหนดส่งงานข้างต้น
